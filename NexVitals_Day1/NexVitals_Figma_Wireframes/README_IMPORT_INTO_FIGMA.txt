NEXVITALS FIGMA WIREFRAME STARTER
Extract this ZIP. In Figma, open your design file and drag each SVG from File Explorer onto the canvas (or use File > Place image). Each SVG is 390 x 844.
Then open Prototype tab and connect:
Welcome Get Started -> Language Selection
Language Continue -> Patient Login
Language Back -> Welcome
Login Register here -> Registration
Registration Login -> Patient Login
Set each interaction to On click > Navigate to > destination.
Click Present to test.
Note: SVGs provide ready-made visual wireframes. Figma prototype links must be added inside Figma. Login method, registration fields, supported languages and consent wording are provisional pending company confirmation.
